# ILBM v2 试运行说明

当前版本：`0.2.1`

## 打开

1. 更新/安装 `https://github.com/shayo-yoo/ILB-memory`。
2. 刷新 SillyTavern。
3. 打开扩展设置中的 **ILB-Memory 记忆管理**。
4. 点击 **打开 ILB-Memory 记忆管理面板**。

## 推荐验收顺序

### 1. 测试 direct 标记

输入：

```text
铁匠将短剑交给甲。(((ILBM:[entity:甲] 转移 [entity:短剑] 给 [entity:乙])))
```

点击“测试标记”。确认：

- 正文副本不再显示 marker；
- 结果中有 `triggered`；
- 解析错误会显示，不阻塞聊天。

### 2. 注册实体

在“实体管理”输入：

```text
短剑
```

点击“注册实体”。重复注册会自动编号，不会静默合并。

### 3. 查看事件

在“事件记录”点击“查看事件记录”。

- `pending`：等待下一层用户消息确认；
- `valid`：参与当前状态和注入；
- `invalid`：保留历史但查询跳过。

输入记录 ID 可查看完整事件详情。

### 4. 手动确认

点击“确认上一层待确认事件”。确认后重新查看事件状态。

### 5. 测试失效

输入楼层号，点击“作废该楼层及之后”。确认：

- 当前状态重新计算；
- 被作废记录仍保留；
- 被作废记录不再参与回放/注入。

### 6. 查看状态卡和实体时间线

- “查看分类状态卡”：物品/人物/地点分类状态；
- 输入实体短名或 ID 后点击“查看实体时间线”。

## 当前限制

- direct 标记已经能生成 pending 事件，但复杂动作的状态变更仍在完善；
- `[entity:短名]` 到稳定实体 ID 的自动绑定仍需加强；
- post 外部 API 提取尚未启用；
- 关系线补充尚未实现；
- 真实手机 WebView 和真实 chat 备份/分叉继承仍需人工验收；
- 当前 UI 是试运行调试界面，不是最终产品界面。

## 反馈信息

出现问题时，请复制：

- 面板中的“运行状态”；
- 事件详情；
- 失败日志；
- 当前聊天楼层和操作步骤。
