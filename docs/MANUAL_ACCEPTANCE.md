# ILBM 第二阶段人工验收清单

> 自动测试已覆盖数据模型、校验、失败降级和调试面板桩。以下项目需要在真实 SillyTavern 页面中由用户确认。

## A. 调试面板

- [ ] 打开 ST 页面右下角的 `ILBM` 按钮。
- [ ] 在“标记处理结果”输入 `测试文本 (((ILBM)))`，点击“测试标记处理”。
- [ ] 结果中 `triggered` 为 `true`，`displayText` / `promptText` 不含 `(((ILBM)))`。
- [ ] 在“手动记忆测试”添加一个实体和一条事件。
- [ ] “可读记忆视图”出现当前实体、当前状态和回放记录。
- [ ] 修改活跃窗口/回放窗口层数后点击刷新，回放条数发生符合预期的变化。
- [ ] 使用“预览候选事件”时，原始事件数量不增加；使用“导入候选事件”后才增加。
- [ ] 粘贴格式错误的 AI 响应，失败日志显示原因且聊天不受影响。
- [ ] 点击“导出记忆备份”，保存 JSON；清空后再导入，实体和事件恢复。
- [ ] 先点击“预览记忆注入文本”，确认内容；确认后再选择“开启记忆注入”并“立即应用注入”。
- [ ] 点击“关闭并清除注入”，确认下一轮状态中不再保留 ILBM 注入块。

## B. 真实聊天路径

- [ ] 发送一条包含 `(((ILBM)))` 的 assistant 回复，用户界面看不到标记。
- [ ] 确认下一次 Chat Completion 请求中看不到标记。
- [ ] 确认标记所在的原始聊天消息仍可追溯，不被静默改写。
- [ ] 编辑一条消息后，指定楼层及之后的记忆记录显示为无效。
- [ ] 切换 Swipe 后，非选中分支记录无效，选中分支保留。
- [ ] 删除消息后，聊天仍正常生成，记忆处理失败不会阻塞对话。

## C. v2 事件/实体列表（0.5.0）

- [ ] 打开“事件记录”，默认列为楼层、序号、实体、动作、提取模式，顺序为 `(楼层, 楼内序号)`。
- [ ] 默认看不到状态；点击“显示全部状态”后每行追加状态，按钮变为“隐藏状态列”。
- [ ] 点击某行“详情”，展开显示状态、来源消息、Swipe、互动分组、状态变更和正文。
- [ ] 输入实体短名筛选，只保留相关事件且顺序不变；点击“清除筛选”恢复全部。
- [ ] “刷新实体列表”显示短名、类型、状态摘要、关联事件数；点击“时间线”打开该实体时间线。
- [ ] PC 与手机视口下列表不横向溢出，按钮可见可点。

## D. 未纳入当前阶段

- AI 自动调用和语义事件提取；当前只能通过“模拟 AI 提取”注入一个外部适配器，默认关闭。
- 自动实体解析、别名合并、回忆/计划/假设分类。
- 回放内容默认自动注入模型；当前必须由用户手动开启注入。
- 关联历史补充和 token 精确计费。
